# スマートフォン実機テスト計画 / Voice Bridge IME

---

## 1. 基本方針

- Phase ごとに実機テスト項目を持つ
- エミュレータでの確認は補助、合否判定は実機で行う
- IME / マイク / Overlay / 録音中通知は全て実機で検証する
- ChatGPT / Chrome / Gmail / LINE / メモ など主要アプリで挿入確認する

---

## 2. テスト端末

| ロール | 機種条件 | 例 |
| --- | --- | --- |
| Primary | Android 14 以上 / 主要メーカー | Pixel 8 系 |
| Secondary | Android 13 / 高シェア機 | Galaxy S22 |
| Low-end | Android 12 / メモリ少なめ | エントリー機 |

最低 1 機種は実機必須。CI のエミュレータは UI 計算上の確認用とし、IME 有効化フローや SpeechRecognizer の挙動は実機で必ず追試する。

---

## 3. Phase ごとのテスト

### Phase 1: Android プロジェクト作成

- [ ] 実機にインストールできる
- [ ] アプリ起動でクラッシュしない
- [ ] バージョン名・アイコンが表示される

### Phase 2: 最小 IME で固定文挿入

- [ ] 設定 → 言語と入力 → 画面キーボードで Voice Bridge IME を有効化できる
- [ ] IME Picker から Voice Bridge IME を選択できる
- [ ] ChatGPT アプリの入力欄に「テスト」を挿入できる
- [ ] Chrome の検索欄に「テスト」を挿入できる
- [ ] 標準メモアプリで挿入できる
- [ ] LINE のトーク入力欄で挿入できる
- [ ] Gmail の本文に挿入できる
- [ ] 挿入時にアプリがクラッシュしない

### Phase 3: Onboarding

- [ ] Step 1〜6 を順に進められる
- [ ] IME 有効化ボタンで設定画面へ遷移できる
- [ ] 戻ってきた際に状態が再評価される
- [ ] マイク権限ダイアログが正しい説明文で表示される
- [ ] Overlay 権限が「任意」と分かるラベルで表示される
- [ ] 拒否しても Onboarding を完了できる

### Phase 4: 単発音声入力

- [ ] 単発録音ボタンタップで録音が始まる
- [ ] 録音中の音量バーが反応する
- [ ] 発話終了で自動停止する
- [ ] 文字起こし結果が入力欄に挿入される
- [ ] 連続 3 回認識失敗で停止し Error 表示
- [ ] 端末をマナー / 機内モードにしても落ちない

### Phase 5: 履歴 DB

- [ ] 単発録音後、履歴に 1 件追加される
- [ ] 履歴画面で一覧表示される
- [ ] 個別削除できる
- [ ] 全削除できる
- [ ] アプリ再起動後も履歴が保持される
- [ ] 全データ削除で履歴が消える

### Phase 6: 辞書補正

- [ ] 辞書登録した語が認識結果で置換される
- [ ] 無効化した辞書は置換されない
- [ ] 履歴詳細から辞書登録できる
- [ ] アプリ再起動後も辞書が保持される

### Phase 7: Overlay

- [ ] Overlay 権限が必要な時のみ要求される
- [ ] フローティングボタンが画面端に表示される
- [ ] ドラッグで移動できる
- [ ] 長押しで非表示にできる
- [ ] Overlay 拒否しても IME 内ボタンで録音できる
- [ ] `playNoOverlay` ビルドでは Overlay 関連 UI が出ない

### Phase 8: 継続録音

- [ ] ダブルタップで継続録音が始まる
- [ ] セグメントごとに入力欄へ追記される
- [ ] 再タップで停止する
- [ ] 10 分上限で自動停止する
- [ ] 画面ロック中は停止する
- [ ] 低バッテリーで自動停止する

### Phase 9: Play release 準備

- [ ] `play` flavor で `.aab` がビルドできる
- [ ] `playNoOverlay` flavor で `.aab` がビルドできる
- [ ] internal track にアップロードできる
- [ ] クローズドテスト 12 人 × 14 日のセットアップが完了する

## 5. 障害観測項目

- IME 有効化に失敗するアプリ
- 挿入できないアプリ (`InputConnection` が null になるケース)
- SpeechRecognizer がタイムアウトする頻度
- マイク権限拒否時の UX
- Overlay 権限拒否時の UX
- 録音中 UI が出ない事象
- 文字起こし結果が空になる頻度
- 継続録音が途中で停止する事象
- 端末発熱・バッテリー消費

- [ ] LINE で単発挿入

---

## 7. ベータテスト計画 (Phase 9)

- 期間: 14 日
- 人数: 12 名以上 (Play 要件を満たす)
- 端末: Android 12 / 13 / 14 / 15 を含む
- 配布: クローズドテストトラック
- 回収項目:
  - クラッシュ率
  - IME 有効化完了率
  - 主要アプリでの挿入成功率
  - マイク / Overlay 権限の許可率
  - ユーザーからの不満コメント
- 終了条件: クラッシュ率 1% 未満かつ主要アプリ挿入成功率 95% 以上

---

## 8. 緊急ロールバック条件

- クラッシュ率 2% 超
- マイク権限を理由としたアンインストール率 30% 超
- Overlay 周りで OS 制約に抵触
- Play Console から policy violation 警告

該当時は `playNoOverlay` への切替、または Production からの撤回を行う。
