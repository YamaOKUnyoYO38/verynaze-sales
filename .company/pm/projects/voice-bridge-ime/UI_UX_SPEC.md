# UI / UX 仕様 / Voice Bridge IME

---

## 1. UX 7 原則

1. 入力を邪魔しない
2. 録音状態が一目で分かる
3. 許可・録音・保存の意味が明確
4. 権限拒否でも最低限使える
5. 履歴と辞書はすぐ修正できる
6. Google Play 審査で説明できる UI にする
7. すべての重要データはフル表示・コピペ可能・編集可能・保持可能にする

## 3. Onboarding

| Step | 内容 |
| --- | --- |
| 1 | このアプリは IME ですと案内。他アプリの入力欄に音声入力するために IME として有効化する説明 |
| 2 | Android 設定画面へ誘導 (`ACTION_INPUT_METHOD_SETTINGS`)。戻ってきたら状態を再チェック |
| 3 | Voice Bridge IME を選択 (`InputMethodManager.showInputMethodPicker()`)。選択済みか確認 |
| 4 | マイク権限。録音ボタンを押した時だけマイクを使うと説明し許可ボタン |
| 5 | Overlay 権限 (任意)。画面端ボタンが欲しい場合のみ。拒否しても IME 内ボタンで使える |
| 6 | テスト入力。入力欄に「テスト」を挿入できるか確認 |

## 5. フローティングボタン (Overlay)

### 5.1 ジェスチャ

| 操作 | 挙動 |
| --- | --- |
| 1 回タップ | 単発録音開始 |
| 600ms 以内に 2 回タップ | 継続録音開始 |
| 録音中タップ | 停止 |
| 長押し | ミニメニュー表示（履歴 / 辞書 / 設定 / ボタン非表示） |
| ドラッグ | 位置移動 |
| 画面端へ近づける | 端に吸着 |

### 5.2 ミニメニュー

```text
┌──────────────────────────────────────────────┐
│ 🎙 単発 | 🔁 継続 | 📘 辞書 | 🕘 履歴 │
└──────────────────────────────────────────────┘
```

## 6. IME 内マイクツールバー

Overlay を使わなくても全機能が使えるよう、IME 上部に薄いツールバーを表示する。

- 単発録音ボタン
- 継続録音トグル
- 音量バー
- 直近結果プレビュー
- 履歴 / 辞書ショートカット

---

## 7. 状態表示メッセージ

| State | メッセージ |
| --- | --- |
| `Idle` | 「音声入力できます」 |
| `Listening*` | 「録音中」 + 音量バー |
| `Transcribing` | 「文字起こし中」 |
| `Committing` → 完了 | 「入力しました」 |
| `Error` (認識) | 「認識できませんでした」 |
| `Error` (挿入) | 「クリップボードにコピーしました」 |

---

## 8. ボタン配置原則

- IME ツールバーは画面下端から触れる位置に配置
- Overlay ボタンは画面端吸着、長押しで非表示
- 録音中インジケータは常に画面上に出す（通知 + UI バッジ）
- 録音停止ボタンは常に 1 タップで到達できる

---

## 9. アクセシビリティ

- 主要ボタンに `contentDescription` を設定
- 色だけで状態を伝えない (アイコン形状 + テキスト)
- フォーカスリングを残す
- スクリーンリーダーで状態テキストが読み上げられる
